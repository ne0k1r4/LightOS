# LightOS

A gothic anime Hyprland desktop for Arch Linux — Death Note themed, Misa Amane aesthetic, with a full suite of custom widgets, launchers, wallpapers, and icon themes.

![LightOS Desktop](desktop/skel/.config/hypr/welcoming/welcome.png)

## Install on Arch Linux

### Option 1 — From the ISO

1. Download the latest LightOS ISO from [Releases](https://github.com/ne0k1r4/LightOS/releases)
2. Flash it to a USB drive:
   ```sh
   dd if=lightos.iso of=/dev/sdX bs=4M status=progress && sync
   ```
3. Boot from USB, install Arch with `archinstall`, then run the desktop installer:
   ```sh
   curl -fsSL https://raw.githubusercontent.com/ne0k1r4/LightOS/main/install/install-lightos.sh | bash
   ```

### Option 2 — On an existing Arch Linux system

Clone the repository with all components:
```sh
git clone --recurse-submodules https://github.com/ne0k1r4/LightOS.git
cd LightOS
```

Run the installer:
```sh
bash install/install-lightos.sh --apply
```

Optionally install the LightOS GRUB theme:
```sh
bash install/install-lightos.sh --apply --with-grub
```

That's it. The installer sets up Hyprland, Waybar, all widgets, wallpapers, icons, fonts, and shell config. Log out and select Hyprland from your display manager.

## Requirements

- Arch Linux (fresh install recommended)
- Internet connection during install
- No other desktop environment required

## Wallpaper-Driven Waybar Colors

LightOS automatically changes the Waybar color scheme every time you switch wallpaper. No manual theming needed.

- Selecting any wallpaper (image or video) samples its dominant colors
- A palette of 6 CSS variables is generated: `accent`, `soft`, `pale`, `deep`, `ink`, `text`
- Waybar reloads instantly with the new palette
- The workspace switcher glow colors also update from the same palette
- Videos are sampled at the 1-second mark for color extraction

The palette is generated by `~/.config/waybar/Scripts/wallpaper-colors.py` and written to `~/.config/waybar/wallpaper-colors.css`, which both the Light and Dark Waybar themes import automatically.

Wallpaper can be changed via:
- `Super + Shift + W` — Rofi wallpaper picker (images + videos, Light and Dark)
- Waybar wallpaper module click

## Audio Visualizer

A GTK3 layer-shell wave visualizer sits at the bottom of the screen and reacts to system audio in real time.

- Smooth cubic bezier wave with gradient fill
- Colors driven by the active wallpaper palette
- Two variants: `visualizer-light` and `visualizer-dark`
- Sensitive at low volumes — boosted gain for quiet media
- Small artwork icons float above the wave peaks
- Launched automatically at startup via Waybar or manually:
  ```sh
  ~/.config/Light/bin/visualizer-light &
  # or
  ~/.config/Light/bin/visualizer-dark &
  ```

## LightOS Animated Capsule

The default desktop bar is an Eww-based animated capsule that floats at the top center of the screen.

**Features:**
- Compact pill shape that expands on hover
- Animated neon ray sweep during expansion
- Glowing pixel heart animations (frame-based SVG)
- Music playback indicator with disc icon
- Battery percentage with cyan progress bar
- Clock and workspace indicator
- Full module dropdown (wifi, bluetooth, volume, brightness, temp, memory)
- Wallpaper-driven color palette (auto-updates)
- Translucent glass styling with blur

**Keybinds:**
- `Super + Control` — Toggle bar visibility
- Click bell icon — Open module panel
- Click disc/music — Play/pause media
- Hover — Expand to show extra controls

**Switch to Waybar:**
```sh
~/bin/toggle-bar.sh
# Or edit ~/.config/hypr/auto_start.lua and comment/uncomment the bar lines
```

**Customization:**
- Colors: `~/.config/eww/pink-capsule/_dynamic.scss` and `_wallpaper.scss`
- Module actions: `~/.config/eww/pink-capsule/action.sh`
- Status polling: `~/.config/eww/pink-capsule/status.sh`



| Key | Action |
|---|---|
| `Super + T` | Open terminal (kitty) |
| `Super + L` | Open launcher |
| `Super + Tab` | Workspace switcher |
| `Super + Shift + W` | Wallpaper picker |
| `Super + Q` | Close window |
| `Super + M` | Power menu (shutdown / reboot / lock / logout) |
| `Super + 1–9` | Switch workspace |
