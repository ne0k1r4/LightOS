# LightOS projects

The local project set is split by purpose:

- `LightOS` — Arch ISO profile and core desktop setup.
- `LightOS-Downloader` — standalone Qt 6 direct-URL download app.
- `LightOS-Assets` — original scalable LightOS application, file-type, and status icons.

Each project builds and installs independently. The core installer does not clone or require either optional project. Each repository is local until its contents, license, and release have been reviewed.
